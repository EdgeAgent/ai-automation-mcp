# Scrub checklist

Run every item for every number, in order. Any "no" stops the action.

- [ ] The lead came from a list graded by the lead-list-checker skill,
      and this row is grade A (or B with the gap accepted by the user).
- [ ] The number is dialable as given (10 digits after normalization).
- [ ] The number is **not** on the never-contact list.
- [ ] The person has not previously asked us to stop calling or texting.
- [ ] The number is a business number, or we have consent to call it.
- [ ] The local time at the number is within lawful, courteous calling
      hours.
- [ ] The script/body says who we are in the first sentence.
- [ ] The script/body contains no claim we cannot back up.

Keep the completed checklist with the outreach record. If a list has no
never-contact source to check against, that is a "no" until one exists.
